# Roadmap

`commit-discipline-mcp` is usable today. This roadmap describes likely directions, not fixed promises; priorities will follow real-world feedback and clearly demonstrated needs.

## Current foundation

- Cross-platform CLI and MCP stdio server.
- Codex, Claude Code, and Cursor project initialization.
- Ordered 2–4 stage plans with exact file scopes.
- Pre-commit test gates and diff-size limits.
- JavaScript, Python, Go, Rust, and Make test detection.
- Windows, Linux, and macOS CI and registry smoke tests.

## Near-term candidates

- More copy-pasteable recipes for common monorepo layouts.
- Improved diagnostics for generated files and multi-ecosystem repositories.
- Additional MCP-client setup guides.
- Machine-readable plan templates for common task types.
- Expanded performance reporting across larger repositories.

## Later exploration

- Opt-in hooks for custom policy checks.
- Richer stage dependency and retry reporting without adding workflow complexity.
- Import/export adapters for issue trackers and planning formats.

## Help shape the roadmap

Open a feature request describing the underlying workflow problem, the repositories or clients affected, and why existing configuration cannot solve it. Concrete reproductions and small designs are more useful than broad feature lists.
