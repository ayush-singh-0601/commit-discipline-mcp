# Support

## Usage questions

Start with these resources:

- [README](./README.md) for installation and configuration.
- [Guided quickstart](./docs/quickstart.md) for a complete disposable-repository demo.
- [Architecture](./docs/architecture.md) for design and trust boundaries.
- [Examples](./examples/) for starter plan and configuration files.

If the answer is not covered, open a GitHub Discussion in the **Q&A** category. Include your operating system, Node.js version, Git version, coding client, and the command you ran.

## Bug reports

Use the structured bug-report form. A useful report contains:

- Package version from `commit-discipline --help` or `npm view commit-discipline-mcp version`.
- Operating system and shell.
- Node.js and Git versions.
- Codex, Claude Code, Cursor, or CLI usage.
- Minimal reproduction steps in a disposable repository.
- Sanitized error output.

Never paste npm tokens, GitHub tokens, environment secrets, or private source code.

## Security issues

Do not report vulnerabilities through Discussions or public issues. Follow [SECURITY.md](./SECURITY.md).
